# src-tauri 分层重构计划

## Summary

目标只重构 `src-tauri`：把 Tauri 侧靠近窗口、托盘、命令、IPC 的“前端适配层”按现有前端 `src` 的业务域思路拆分；把桌面扫描、Shell/Win32、接管控制、自启等“后端业务能力”按 Spring Boot 风格拆成 `interfaces / application / domain / infrastructure`。

本次重构以“不改前端 `src`、不改变现有命令签名、先保持行为可构建”为第一阶段目标；桌面接管里过大的 `takeover.rs` 作为重点拆分对象。

## Key Changes

- 建立 `src-tauri/src/interfaces` 作为 Tauri 入口适配层：
  - `commands`：只保留 `#[tauri::command]`、参数转换、错误文案。
  - `tray`：托盘菜单、托盘事件、窗口展示请求。
  - 这一层可以依赖 application，但不直接碰 Win32、Shell、扫描细节。

- 建立 `src-tauri/src/application` 作为应用服务层：
  - `desktop_service`：桌面快照、按路径解析项目、打开项目、右键菜单。
  - `desktop_takeover_service`：启停接管、同步运行时状态、刷新原生层。
  - `app_settings_service` / `tray_service`：自启、托盘状态同步。
  - 这一层负责业务编排，保持类似 Spring Boot 的 Service 语义。

- 建立 `src-tauri/src/domain` 作为领域模型层：
  - 迁入现有 `DesktopItem`、`NativeDesktopState`、`NativeBoxState`、显示设置等类型。
  - 增加领域级 helper，例如路径主键归一化、Box item 查询、display 参数 sanitize。
  - domain 不依赖 Tauri、Win32、文件系统实现。

- 建立 `src-tauri/src/infrastructure` 作为基础设施层：
  - `desktop/scanner`：真实桌面扫描、Shell 虚拟项解析、图标提取。
  - `desktop/shell`：打开项目、原生右键菜单。
  - `desktop/native_icons`：Explorer 桌面图标层显示控制。
  - `desktop/takeover/*`：拆分原生桌面接管实现。

- `takeover.rs` 拆成模块目录：
  - `runtime`：全局线程、命令通道、公开启停 API。
  - `controller`：Windows message loop 和命令处理。
  - `model`：运行时状态、sanitize、Box/图标查询。
  - `explorer_bridge`：Explorer ListView 读取、坐标检测、隐藏/停放图标。
  - `box_surface`：原生 Box 窗口、绘制、命中测试。
  - `win32`：窗口查找、句柄描述、宽字符转换、Win32 小工具。
  - 非 Windows stub 留在同一模块边界内，避免业务层散落 `cfg`。

- 公共接口保持稳定：
  - Tauri 命令名不变：`get_desktop_snapshot`、`open_desktop_item`、`sync_native_desktop_state` 等继续由 `lib.rs` 注册。
  - 前端传入的 JSON 字段不变。
  - 现有 `NativeDesktopState` / `DesktopItem` 结构不做破坏性字段调整。

- 关于 Box 真归属图标的后续实现边界：
  - 重构完成后，接管逻辑改为：Box 内项目由 Dasktop 原生 Box 自己绘制；Explorer 图标只作为拖入检测来源。
  - 已归入 Box 的 Explorer 图标不再移动到 Box 内坐标，而是停放到不可见区域，避免看起来仍在桌面背景上。
  - Box 移动只移动 Dasktop Box 和内部渲染图标，不再同步移动 Explorer 图标坐标。

## Test Plan

- 结构迁移后先跑：
  - `cargo fmt`
  - `cargo check`

- 功能回归手测：
  - 应用启动后托盘正常显示。
  - 设置页能读取桌面快照。
  - 打开桌面文件、Shell 虚拟项、右键菜单仍正常。
  - 桌面接管启停不会让 Explorer 图标永久隐藏。
  - Box 可显示、拖动、刷新后仍跟随前端状态。

- Box 归属模型手测：
  - 将桌面图标拖入 Box 后，Explorer 原图标不再留在 Box 背景区域。
  - Box 内显示 Dasktop 渲染的图标和名称。
  - 移动 Box 时，Box 内图标随 Box 移动。
  - 退出或关闭接管后，Explorer 图标层恢复可见。

## Assumptions

- 本计划只改 `src-tauri`，不重构前端 `src`。
- “src-tauri 的前端部分”定义为 Tauri 的 UI/IPC 适配层，不是 Vue 前端代码。
- 第一阶段优先保证结构清晰和构建通过；行为修复在接管模块拆完后接着做。
- 项目未上线，所以不保留旧模块兼容入口；迁移后删除旧路径和废弃 re-export。
